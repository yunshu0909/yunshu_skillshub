## 技术细节

- 目录：~/Library/Application Support/CodePal/models/（可用 CODEPAL_MODELS_HOME 改）。本页设置 = 现有 hub.json 加 order[]；审核规则 = 新 review-rules.json（只存 overrides）；审核配置 = 新 review-config.json（0644，原子写），取代 review-models.json。
- 审核配置草案字段：schemaVersion、generator、generatedAt、defaultsVersion、minDevWorkflow、models[]（按顺序：id / family / runner / model / effort / command）、selfReview、gates{ lite.G0 … formal.G4: {maxModels, rounds} }、advanced{ timeoutMinutes, failoverMax, autoExtendRounds }。格式定义放 dev 插件仓，CodePal 按它生成。
- IPC 走 models: 前缀，返回 { success, data, error }：沿用 models:hubList / hubSetEnabled / hubSetEffort，新增 models:hubSetOrder、models:rulesGet、models:rulesSet { key, value }、models:rulesReset。
- Claude Code 端版本：~/.claude/skills/dev-workflow/.claude-plugin/plugin.json 的 version（本机 0.12.10）。
- 待查：Codex 端 ~/.codex/plugins/cache/ 下同时留着多个版本，当前启用哪个要读 Codex 插件配置，实现时核实；读不出时 Codex 端显示「版本未知」（橙），不当作支持（后-09）。
