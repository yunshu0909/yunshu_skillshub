# 桌面外壳惯例 · macOS（兜底用，项目有设计总纲时照总纲）

来源：用量监测重做时的调研与验证（Apple HIG、macOS 日历 / 系统设置 / Finder、Fitness、GitHub 贡献图）。只在项目没有自己的外壳规范时用。

## 窗口外壳

- 尺寸以主进程 `BrowserWindow` 为准：默认宽高、`minWidth / minHeight`、`titleBarStyle`（`hiddenInset` = 红绿灯嵌在侧栏里、无标题文字）、`vibrancy`（`under-window` = 侧栏透壁纸）。侧栏宽去布局组件 / CSS 查。
- 侧栏与工具栏同材质（浅灰 chrome），工具栏与红绿灯行同高（约 52px），底部 0.5px 线与侧栏竖线接成 T 形。这层是把侧栏和内容缝成一体的东西，没有它内容区会像一张网页贴在侧栏旁。
- 页面标题住在工具栏里（15px / 600）。侧栏顶部不放品牌块，品牌与版本号放侧栏底部。
- 内容区贴着侧栏撑满，按平台惯例留 16–20px 内边距，不做居中 max-width 的网页式布局。

## 什么放哪

- 工具栏只放**窗口动作**：导航（‹ ›）、全局操作。数据筛选（时间范围、维度切换）放内容区第一行。
- 一个月改一次的**设置类动作**不做常驻按钮，藏在它管的数字后面，点数字弹层（Fitness：点环 → 改目标）。
- **合计**写成一句话放在格子 / 图上方（GitHub：「1,234 contributions」），不做成角落里的小部件。
- 月份 / 分组名做内容区大标题，翻页箭头贴着标题（macOS 日历）。
- 同一行不混放控件、数据、动作三种性质。

## 材质与控件（Tahoe 之后）

- 玻璃 / 透色只用于导航层（侧栏、工具栏），内容层不透明。
- 控件按系统样式：0.5px 线 + 一层投影，圆角 6；分段控件选中项白底带投影；按钮白底细线。
- 正文 13px，次级 11–12px，大数字用 `ui-rounded, "SF Pro Rounded"` 圆体 + tabular-nums。
- 卡片：浅灰底、圆角 12，不画线不加阴影，靠底块分区。
