# <页名> · 状态清单（草案）

> 页面类型：指标页 / **纯列表页**（无详情区）/ 列表 + 详情页 / 表单页 / 快照页 / 混合。不适用的条目划掉不删。
> 声明了类型就按类型删：纯列表页删掉「未选中 / 详情区空」「选中」「分栏比例」这类条目，别让模板把页面推向它本来不是的形态。
> 「建议显示」列是**示例**（指标 / 月历页与列表 + 详情页各一句），换页先按本页重写。
> 每条 = 状态 → 建议显示。用户只否决；「你直接设计」= 全按建议定；部分否决只复述被否的。
> 交互类条目（C / E 类）的「建议显示」写成「触发 → 显示 → 之后去哪」，第 5b 步画交互流程时直接照着连。
> 已有页面的文案取现有代码原文；需要新写的在条目末尾标「新文案」，等用户确认。

## A 数据

| # | 状态 | 建议显示（示例） |
|---|---|---|
| A1 | 正常 | |
| A2 | 当前 / 最近（今天的、最近打开的、正在进行的） | 指标：蓝底标「今天」；列表：默认选中最近一条 |
| A3 | 数值边界（零 / 极小 / 起点前 / 未来） | 指标页展开填四行：零只写「0」不画进度；极小按单位规则；起点前与未来留白不可点。非指标页整条划掉 |
| A4 | 整页无数据（源不存在 / 为空） | 整页空态一句话 + 主动作 |
| A5 | 未选中 / 详情区空 | 默认选第一项避免出现；避免不了才一句话 |
| A6 | 条目过多（列表 / 结果 / 正文各答一行） | 列表：分组 + 滚到底加载；结果：上限 + 提示缩小范围；正文：以关注点为中心展开、其余折叠；指标：前 N + 「其他 M 个」 |
| A7 | 标题 / 名字过长、未归一、含系统前缀 | 单行省略 + hover 全名；取路径末段；跳过系统前缀 |
| A8 | 多来源混合 | 不标来源，除非用户要按来源看 |
| A9 | 内容渲染失败 / 格式异常 | 该条回退纯文本 + 角标；坏行跳过并计数 |
| A10 | 单条内容过长 / 过宽 | 超过 N 行折叠「展开全文」；宽内容横向滚动，正文区不横向滚 |
| A11 | 数据正在变化（外部写入 / 删除） | 标「进行中」；被删项灰置不静默消失 |
| A12 | 搜索 / 筛选无结果 | 保留输入与旧详情，结果区一句话 + 清空；与 A4 区分 |

## B 计算

| # | 状态 | 建议显示（示例） |
|---|---|---|
| B1 | 首次 / 未缓存 / 长计算 | 骨架占位；超过 1s 给进度（已完成 N / M），边算边出，不清空旧结果，不整页让位 |
| B2 | 单点失败 | 该项「—」+ hover 重试 |
| B3 | 整体失败 | 保留骨架 + 一行错误 + 重试按钮 |
| B4 | 进行中 vs 无结果 | 进行中转圈不清空；结束无结果才显示 A12 |

## C 设置与动作

| # | 状态 | 建议显示（示例） |
|---|---|---|
| C1 | 从未设置 | 无进度模式 + 「未设置 · 设置」入口 |
| C2 | 口径 | 只设一个值，派生值自动算 |
| C3 | 打开编辑 | 点数字本身，弹层锚定；低频动作不做常驻按钮 |
| C4 | 保存 | 回车 / 失焦保存 + Toast + 即时重算 |
| C5 | 非法 / 不足输入 | 表单：红边不保存；搜索：不发请求不报错 |
| C6 | 破坏性动作 | 二次确认 + 成功 Toast |
| C7 | 动作不可用 | 禁用 + hover 说原因 |
| C8 | 动作结果 | 成功 / 失败各一条 Toast 文案 |
| C9 | 处理中 / 写入中 | 点了之后到出结果之间：按钮文案「xx 中...」并禁用，防重复点；点即保存、失焦保存也有这一态 |

无设置项的页面 C1–C4 划掉。

## E 交互

| # | 状态 | 建议显示（示例） |
|---|---|---|
| E1 | 选中 | 进页默认选当前 / 最近项；切换后详情保留还是清空；结果点击后高亮 |
| E2 | 列表 / 翻页边界 | 有翻页：到头变灰；无翻页：滚到底加载更多 / 「共 N 条」 |
| E3 | 键盘 | 不给默认答案。列候选（↑↓ 切项、Enter 打开、Esc 清搜索、⌘F 聚焦）让用户否决；找东西为主的页面不能「先不做」 |
| E4 | hover | 按项目视觉规范（CodePal：边框加深不变浅）；hover 提示只用于 A7 / B2 / C7 这类信息补充，不做装饰性 tooltip |
| E5 | 时区 / 日界 | 沿用现有口径 |
| E6 | 模式切换（搜索 ↔ 浏览 / 筛选前后） | 选中项、滚动位置、详情是否保留 |
| E7 | 定位导航 | 命中首条 / 上一处 / 下一处；命中在折叠区时自动展开 |
| E8 | 外部变化 | 文件被删 / 新增：列表如何刷新，不静默 |
