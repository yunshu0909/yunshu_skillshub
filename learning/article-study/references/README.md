# 物证说明

## 物证-交互演示.html

真实案例：教「TDD 跑红」这个抽象概念时，文字讲了两轮没通，改用这个页面一点就懂。

**照抄的是工艺，不是内容**：

1. **页面里嵌一个真能跑的最小系统**（纯 JS 模拟即可，不需要真后端）
2. **左右分栏**：左边是不变的部分（测试代码），右边是可切换的部分（三个版本的实现）
3. **三态切换**：🈳 空壳版（该失败）/ ❌ 写错版（**故意演示失败**——这是灵魂）/ ✅ 正确版
4. **一个大按钮「▶ 运行」**：点了逐行吐结果，带颜色和图标，最后给退出码/判定
5. **顶部四步操作指引**：用户跟着点就行，不用猜怎么玩
6. **底部三态对照表 + 一个比方 + 一句金句**：把体验固化成认知

**关键设计原则**：不要只演示成功。让用户亲眼看到"一个自信的错误答案被机制当场抓住"——这个瞬间的说服力，抵十遍解释。
