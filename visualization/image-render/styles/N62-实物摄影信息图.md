- 不适合 / 作者没选过：同一轮的 N63 黏土、N64 微缩沙盘、N65 博物馆、N66 便当格、N67 拼贴、N68 新粗野、N69 液态玻璃都没选

## 风格块（逐字粘贴，不得改写）

```style
实物质感的信息图幻灯片：所有图表和图形都由真实物件搭成（亚克力、纸张、木块、金属小件），放在干净的浅暖灰桌面上，用柔和的影棚光拍摄，有真实的投影和景深，像高端品牌的产品摄影；标签是立在桌上的白色小卡片或贴纸，文字为清晰的深色粗黑体中文；标题用深色粗黑体放在画面上方空白处。
不要：卡通、扁平插画、霓虹、杂乱背景、品牌标志。
```

## 叙事语法（适配画面时照这个设计）

- 每页一个 exhibit，用这个风格的原生材料 / 场景把它「做出来」。
- 用户喜欢的点：像真人拍的实物（真实投影、浅景深、皮革/亚克力/纸的材质），配色克制（浅暖灰 + 白卡 + 一个橙色重点物件），大面积留白放粗黑体字。
- 比喻用实物讲：塞满揉皱纸的亚克力管 vs 只放三件东西的空管；橙色物件固定代表「重点 / Skill」。
