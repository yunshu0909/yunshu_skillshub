# S08 · 漫画网点

- 类别：有角色讲故事　档位：**主力**（被作者选中 5 张）
- 适合：前后对比、情绪、踩坑故事、1:1 一句话
- 不适合 / 作者没选过：表情包、系列图（用户都没选）、图片版 PPT（2026-10-03 一套 4 页都没选）

## 风格块（逐字粘贴，不得改写）

```style
日式黑白漫画风：粗细变化的墨线，网点纸表现灰阶，必要时加速度线或集中线增强戏剧感；人物为 Q 版夸张表情；全图黑白灰，无彩色。文字为黑色粗黑体，放在白底方框内。
不要：任何彩色、3D、写实、照片质感。
```

## 叙事语法（适配画面时照这个设计）

- 标题：顶部横贯的白底旁白框。
- 并列：竖格并排，粗黑分格线，每格底部白底旁白框。
- 对比 / 前后：用分格代替箭头，时间顺序就是阅读顺序；后一格用集中线放大情绪。
- 情绪：Q 版抱头尖叫、汗滴、物件冒烟、东西雪崩。
- 轻松：瘫在椅子上、闭眼微笑、闪光。
- 结论：人物的白底对话气泡，或整页底部横向旁白框。

## 文字放在哪

旁白框、对话气泡；黑色粗黑体。

## 已知坑

天然想加拟声词，靠「只画引号内文字」约束住。
