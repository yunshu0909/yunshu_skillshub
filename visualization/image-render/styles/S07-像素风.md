# S07 · 像素风

- 类别：游戏感　档位：**主力**（被作者选中 6 张）
- 适合：分类、任务清单、对比、关卡式流程、9:16 竖屏
- 不适合 / 作者没选过：表情包、系列图

## 风格块（逐字粘贴，不得改写）

```style
16-bit 像素艺术：清晰可见的方形像素格，有限调色板（约 16 色），复古游戏画面感；人物和物体都是像素小人和像素道具；浅色纯色背景。文字为清晰的粗黑体中文（文字本身不做像素化，保证可读）。
不要：平滑矢量线、3D 渲染、写实、模糊。
```

## 叙事语法（适配画面时照这个设计）

- 世界观：复古 16-bit RPG / 横版平台游戏。
- 标题：顶部像素边框的游戏标题栏。
- 分类：「选择角色」界面——像素选择框并排，每框下面一块像素名牌。
- 清单：任务公告板，每张任务卷轴一个图标 + 绿色对勾。
- 对比：两个战斗场景左右并排，状态用头顶能量条（半格绿 → 全满红）。
- 负载 / 压力：任务、窗口变成围攻角色的小怪物。
- 流程：横版地图；「以后再做」= 上锁的关卡。
- 9:16：手机竖屏游戏，从上到下三个房间场景。
- 结论：底部游戏提示框（可带 ▼ 翻页符）。

## 文字放在哪

游戏标题栏、像素名牌、对话框、提示框；字用清晰粗黑体，不像素化。

## 已知坑

爱加 NPC 和宠物；9:16 时像素格容易变淡，适配时写「像素格清晰可见」。不适配直接套用会像 PPT。
