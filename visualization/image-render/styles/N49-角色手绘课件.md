# N49 · 角色手绘课件

- 类别：有角色讲故事　档位：**特定**（作者的 IP 系列选中过 2 张，换角色实测 3 张）
- 适合：「XX 小课堂」系列的图片版 PPT、教程讲解（16:9），你自己的 IP 当老师
- 不适合 / 作者没选过：—
- **必须垫图**：`--ref <你的角色参考图>`。没有参考图会画成一个随机的默认角色。

## 风格块（逐字粘贴，不得改写）

```style
小课堂 · 手绘讲课幻灯片：一页讲课 PPT 的画面，整体是彩铅 + 水彩手绘质感，浅色干净的纸张背景，留白充足，像精心设计的手绘课件。主角是参考图里的那个角色（长相、毛色、服饰和配饰都照参考图），在画面里当老师；配角是一个圆滚滚的白色小机器人（屏幕脸、两个圆点眼睛、头顶一根短天线），代表 AI。标题是大号手写感粗体中文，要点写在圆角便签卡片或手绘小木牌上，字迹清晰整齐。
不要：照片质感、3D 渲染、写实人物、密密麻麻的小字、品牌标志。
```

## 叙事语法（适配画面时照这个设计）

- 画面里提到主角就用角色名（如「橘子」），第一次出现时补半句外貌（「戴圆框眼镜、系红围巾的胖橘猫橘子」），跨页才稳定。
- 标题：左上角大号手写粗体，下面可衬一道浅色水彩色带；章节页标题居中。
- 要点：圆角便签卡片（竖排或横排），卡片左边一个小图标。
- 对比：左右两半，同一个角色在两种处境里（被纸堆淹没 vs 从工具箱有序取用）。
- 流程：踏脚石、台阶、小路，主角走在上面。
- 概念：用实物比喻（钥匙开门、手册、书架、流水线），主角拿教鞭讲解，小机器人动手做。

## 文字放在哪

左上标题；便签卡片、小木牌、手绘横幅。

## 已知坑

- 角色画风和彩铅不一样时（比如 Q 版卡通角色），会被画成彩铅版，但长相能认出来（2026-10 换角色实测）。
