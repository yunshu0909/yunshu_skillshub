# N27 · 四格漫画

- 类别：有角色讲故事　档位：**待验证**（被作者选中 1 张）
- 适合：发现 / 踩坑故事、四条规则
- 不适合 / 作者没选过：—

## 风格块（逐字粘贴，不得改写）

```style
彩色四格漫画：四个等大的格子（排列方向见画面描述），干净的黑色线条，平涂明快颜色，Q 版人物表情生动。文字为清晰黑体，作为格子底部的字幕。
不要：拟声词、格子编号、清单以外的文字。
```

## 叙事语法（适配画面时照这个设计）

- 起承转合：起因 → 翻车 → 换做法 → 成功。
- 字幕只放关键格（例如第 2、4 格），其他格靠画面讲。
- 横版 16:9 横排一行；竖版 3:4 从上到下竖排。

## 文字放在哪

格子底部字幕。

## 已知坑

风格块里不要写排列方向，交给画面描述。
