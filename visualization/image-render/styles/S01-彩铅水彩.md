# S01 · 彩铅水彩

- 类别：手作感　档位：**主力**（被作者选中 6 张）
- 适合：信息图、清单、时间线、9:16 长图流程
- 不适合 / 作者没选过：表情包（用户没选）

## 风格块（逐字粘贴，不得改写）

```style
奶油色纸张底，纸纹清晰可见；彩色铅笔线稿，笔触可见；淡水彩上色，轻微晕染，颜色不出边也不满涂；暖色调，干净明亮；少量轻涂鸦小装饰（小星星、小弧线）点到为止。文字为工整的深棕色手写感中文。
不要：扁平矢量、3D、摄影写实、强渐变光效、厚重描边。
```

## 叙事语法（适配画面时照这个设计）

- 标题：顶部手写大字，下面衬一道水彩涂抹，两侧可加短线涂鸦。
- 并列：等宽小场景并排、底部对齐，标签直接手写在场景下方，不加框。
- 对比：左右两个场景，中间彩铅粗箭头。
- 流程 / 成长：一条蜿蜒的线（水管、小路）串起几个节点，或植物从种子到开花。
- 情绪：人物抓头、汗珠、小涂鸦符号（漩涡、星星、闪电）。
- 结论：底部一行手写字，同样衬一道水彩。

## 文字放在哪

手写彩铅字本身就是画面的一部分，可以放全部文字（标题 + 标签 + 结论）。

## 已知坑

会自己加小猫、盆栽，约束里禁掉。机械套用也好看，是唯一不太需要适配的风格。
