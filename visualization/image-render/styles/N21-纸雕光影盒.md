## 风格块（逐字粘贴，不得改写）

```style
纸雕光影盒：多层白色和彩色卡纸剪刻叠成，层层纵深，背后透出温暖光晕，层与层之间有阴影；整体装在一个木框里，像立体剪纸灯箱。文字贴在最前层的白色纸条上，清晰。
不要：写实、塑料感、暗淡无光。
```

## 叙事语法（适配画面时照这个设计）

- 结构：木框里层层纸雕——远景光源 / 源头、中景路径、前景人物或小屋。
- 对比：一个框分左右两半，一暗一亮。
- 流动：纸雕河流、水渠、飘出的星星和小画框，把「源头 → 你」画出来。
