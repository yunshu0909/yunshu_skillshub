# N41 · 日式手绘动画

- 类别：有角色讲故事　档位：**特定**（被作者选中 2 张）
- 适合：头图、活动海报、氛围
- 不适合 / 作者没选过：—

## 风格块（逐字粘贴，不得改写）

```style
日式手绘动画电影风：水彩手绘背景，温暖的午后光线，蓬松的大积云，细腻的生活小细节；人物线条简洁、表情温和；画面像手绘动画电影里的一帧。文字为干净的圆黑体，深色或白色，清晰。
不要：真实动画角色、3D 渲染、写实照片。
```

## 叙事语法（适配画面时照这个设计）

- 一个人物在开阔风景里安静地做一件事（坐门廊读纸、坐山坡画画）。
- 比喻融进自然：溪水漂来纸张、画里的云飘上天空。
- 大片积云和光线，留出天空放字。

## 文字放在哪

天空里的圆黑体大字。
