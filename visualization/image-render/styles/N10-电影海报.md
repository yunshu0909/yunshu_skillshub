# N10 · 电影海报

- 类别：有角色讲故事　档位：**常用**（被作者选中 3 张）
- 适合：头图、活动海报、故事
- 不适合 / 作者没选过：图片版 PPT（2026-10-03 一套 4 页都没选）

## 风格块（逐字粘贴，不得改写）

```style
戏剧性电影海报：强烈明暗对比，电影级青橙色调，主角有电影感的光，背景有纵深和光束；标题是有电影片名质感的大字。
不要：演职员表、评分、清单以外的日期和小字、真实电影元素。
```

## 叙事语法（适配画面时照这个设计）

- 构图：一个主角 + 有纵深的场景 + 强光束，青橙色调。
- 比喻：用场景里的大道具讲事（身后一长串越画越歪的画布、墙上的水龙头流出发光纸片）。
- 标题：大字放在画面下部；副标题 / 口号在标题上方或下方小一号。
- 海报信息：时间、地点放在最底部两行小字。

## 已知坑

人物会偏写实；电影海报常见的演职员表、评分、上映日期会自己冒出来，风格块已禁；活动海报要的时间地点写进文字清单就行。
