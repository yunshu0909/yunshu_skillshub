# N13 · 便利贴墙

- 类别：手作感　档位：**待验证**（被作者选中 1 张）
- 适合：漏斗、筛选、整理
- 不适合 / 作者没选过：—

## 风格块（逐字粘贴，不得改写）

```style
软木板上的便利贴墙：彩色方形便利贴、图钉、红色细线连接；俯拍，微微阴影；需要写字的便利贴用黑色马克笔手写，其余便利贴都是空白。
不要：便利贴上出现清单以外的字或涂鸦字母、真实品牌标识、杂乱背景。
```

## 叙事语法（适配画面时照这个设计）

- 软木板：乱贴的一大片 → 红线牵到整齐的网格。
- 关键数字写在大一号的便利贴上，其余便利贴全空白。

## 文字放在哪

马克笔手写便利贴、顶部白纸横幅。

## 已知坑

空白便利贴上容易冒出字，约束里强调。
