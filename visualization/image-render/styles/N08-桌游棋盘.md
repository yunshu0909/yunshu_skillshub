- 适合：流程、时间线（16:9）
- 不适合 / 作者没选过：6 项环形清单（用户没选）

## 风格块（逐字粘贴，不得改写）

```style
俯视角的桌游棋盘：彩色格子组成的路径，棋子、骰子放在棋盘上，棋盘边缘露出一点木质桌面；配色明快，插画化，带轻微纸板质感。文字为清晰粗黑体，印在格子或棋盘横幅上。
不要：写实照片、3D 渲染感、真实桌游品牌。
```

## 叙事语法（适配画面时照这个设计）

- 俯视棋盘，路径格子 = 步骤。
- 关键步骤画成放大的特殊格（格里一个图标）。
- 棋子在起点、骰子在旁边，终点格是成果（画框、旗子）。

## 文字放在哪

特殊格下方 / 旁边印字；标题在棋盘上方横幅。
