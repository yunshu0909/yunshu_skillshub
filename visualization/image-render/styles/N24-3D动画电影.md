# N24 · 3D 动画电影

- 类别：有角色讲故事　档位：**主力**（被作者选中 9 张）
- 适合：分工、价格对比、表情包、9:16 分镜流程
- 不适合 / 作者没选过：系列图头图（用户没选）

## 风格块（逐字粘贴，不得改写）

```style
高品质 3D 动画电影画面：圆润夸张的角色造型，大眼睛、表情丰富，柔和的全局光照和景深，温暖明亮的色调，像动画长片里的一帧。文字为干净的粗黑体。
不要：真实电影角色、写实人类、恐怖谷、暗沉色调。
```

## 叙事语法（适配画面时照这个设计）

- 世界观：动画长片里的一帧，明亮室内（工作室、小店、画室）。
- 角色化：概念变成角色——脚本 = 多臂小机器人，模型 = 戴眼镜的猫头鹰；用表情区分好坏。
- 对比：几个角色并排，各自的道具 / 表情说明差异（台秤上厚账单 vs 一张纸 vs 空）。
- 流程 / 一天：竖排分镜帧，细白边分开，每帧下一行字。
- 表情包：2×2 圆角贴纸，同一角色四个动作。

## 文字放在哪

画面上方空白处的粗黑体，或帧下方 / 台前的白色圆角标签。

## 已知坑

多个角色时会长得一样，适配时写清每个角色的区别（颜色、道具、体型）。
