# 实测规则与证据（作者 2026-10 实测，约 400 张图）

| 规则 | 证据 |
|---|---|
| Codex 原样执行提示词，可逐字核对 | 五轮共 170 张，会话日志 revisedPrompt 与提示词文件逐字一致 170/170 |
| 机械套风格不行，必须按风格适配画面 | 01-mac-ai：12 风格机械版 0 张被选；exp-adapt 像素 / 漫画适配版 8/8 被选 |
| 「」只给要画的字 | 「结论：16G…」把「结论：」画进图（S11-2-A）；改成「」包正文 + 注明说明不画后再没出现 |
| 文字的角色名用中性词（左侧名牌、标题、副句），别用画面里本来就会出现的词 | 08 轮像素关卡图：角色名写「第一关」，三块名牌都多画了「第一关 / 第二关 / 第三关」；改成「左侧名牌」后消失。同批「第一步」「第一条」没被画上，游戏关卡牌上写「第一关」太顺理成章 | 10-03 正式风格又一例：角色名「上层/中层/下层」在扁平插画、等距 3D 两版被画成「上层：…」前缀，改成「甲条/乙条/丙条」后消失——**PPT 里的分层、编号类词都别当角色名**。10-03 新世界又一例：画面写「上面一块木牌写甲卡」，绘本、像素两版把「甲卡 / 乙卡」画上了牌子（同批积木、国风、复古没画）——**画面描述里别写「写甲卡」这种把角色名当宾语的句子**，直接写「写『某某』那句话」最稳。
| 画面描述里别用「」 | 04 轮检查脚本拦下「不好看」三个字 |
| 写主体占比 | 02 轮瑞士海报、地铁线路图画面太空；03 轮起写「约四成宽」后没再出现 |
| 风格块不写版式 | 四格风格块写了「横排一行」，竖版要用时冲突 |
| 模型爱加猫、NPC、$ 符号 | 01/03/04/05 轮多次；约束加「不要添加画面描述里没有的小动物」「不要货币符号」 |
| 现编角色写细就能跨图一致 | 05 轮红贝雷帽小机器人：4 种风格 × 2 种画幅、表情包四连都一致，未垫图 |
| 真实角色要垫图 | 哈士奇：纯文字是「模型默认款」，垫图后才是作者家那只；2026-10 换角色测试：橘猫、小熊猫垫图后跨页一致 |
| 垫图只管角色像不像，不管版式和文字 | dog-poster-test：两组文字 17/17 全对、版式几乎相同 |
| 留白靠改结构，不靠写数字 | v0.9：写「约 6% 留白」实测 1.5% |
| 提示词语言 / 长度不影响文字准确 | v0.9：中文短 vs 英文长，文字准确率相同 |
| 一次性出图稳，迭代时跑偏 | v0.8：10-01 8 轮重写提示词、一次改多处 → 风格漂移 |
| 让 Codex 每张出完立刻保存，并放弃卡住的调用 | 10-02 PPT 探索：一批 8 张里 B4 的 imagegen 一直不返回，Codex 打算等全部出完再统一复制，40 分钟超时后已画好的 B1–B3 也没进 out/（事后从 `~/.codex/generated_images/` 按 md5 找回） |
| `num_last_images_to_include` 只能 1–5 | 01 轮写 0，三批全报错 |
| Codex 会满载 | 05 轮一批整批 `Selected model is at capacity`，重跑成功 |
| `codex exec` 要 `< /dev/null` | 否则卡在「Reading additional input from stdin」 |
| 风格块里别写方向和位置 | Codex 审查：N21「横向木框」、N10「主角居中、标题在下部」、N24「文字在上方」与竖版 / 其他用法冲突，已改（这三种的样张是用旧措辞出的） |
| 中文逗号偶尔画成半角样式 | 2026-10 新版测试多次出现；不影响阅读，用户在意就重出那张 |
