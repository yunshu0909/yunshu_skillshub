# 作者口味（五轮 170 张、标喜欢 58 张总结，2026-10-02）

这是作者的偏好，只在用户说「你推荐」时作参考；用户自己点过 ♡ 的风格优先。

## 偏爱

- **有场景、有空间纵深**：舞台、桌面小世界、地图、教室、电影里的一帧、剖面房子。
- **手作 / 玩具 / 游戏感**：彩铅、积木、折纸、蜡笔、便利贴、像素、桌游、等距像素。
- **有角色在讲故事**：漫画、四格、3D 动画、复古广告推销员、电影海报主角。
- **彩色、温暖**。

## 默认不推

- 极简几何、纯排版（瑞士海报、地铁线路图、杂志编辑、说明书）——做得再清楚也没选。
- 单色冷峻（CRT 绿屏、老报纸、水墨、蓝图）。
- 暗色华丽（塔罗牌）。
- **平铺图标 / 徽章 / 贴纸式排版**（羊毛毡徽章、贴纸书、手账相框、6 格横版玩具屋）：可爱但没场景，不选。

## 其他观察

- 机械套风格（同一画面换皮）一张都没选；适配后整套选中。
- 字多不是问题，**字和画是不是同一种材质 / 有没有属于这个风格的载体**才是问题。
- 我（Claude）觉得「比喻最巧」的几张（年画门神分工、刮画留白、水墨杆秤）用户没选——比喻巧不如场景有温度。
