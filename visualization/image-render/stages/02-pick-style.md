# 阶段 2：定风格

## 默认风格（大多数时候）

开工先跑 `python3 $S/settings.py get style`：

- **有默认**：告诉用户「本次用默认风格 X，要换说一声」，直接用它出整套（量产）。
- **没有默认**：打开风格选择页 `python3 $S/style_picker.py <任务目录>/风格选择.html`，让用户看样张挑一种，`python3 $S/settings.py set style <编号>` 存成默认。选择页只显示有样张的风格（内置 + 用户自建）。
- **「这次用 X」**：只这一次，不改设置，在 `scenes.md` 顶部写「本次风格：X」。

## 探索（用户说「给我几个风格看看」）

每张图（或挑 1–2 张代表图）配 **3–4 种**风格，出完让用户挑；问用户要不要把选中的设成默认。

怎么推荐（只在探索或用户说「你推荐」时）：

1. 看画面单的「内容类型」，查 `reference/recommend.md`，先从**主力 / 常用**档里挑（档位是作者口味）。
2. 用户自己点过 ♡、或自建的风格优先；作者口味（`reference/taste.md`）只作参考。
3. 推荐时一句话说清每种风格打算怎么画（比喻），让用户能想象。

## 新风格

见 SKILL.md「新增风格」：新卡写在 `~/.image-render/styles/`，编号 `U01` 起；**用户认可了试图、有了样张才进库**。
