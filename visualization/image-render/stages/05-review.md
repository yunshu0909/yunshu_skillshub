# 阶段 5：挑图、迭代、写回

## 挑图

- 对比页 `review.html`：每张图右上角 ♡ 标记 + 写一句喜欢哪里 → 右下角「复制给 Claude」→ 用户贴回来。
- 标记只存在用户那个浏览器里；换了页面要分别复制。

## 迭代（防跑偏，来自 10-01 的 8 轮跑偏复盘）

1. **满意就冻结**：用户说好的那张，把 `adapt/<名>.txt` 复制到 `baselines/adapt/`、`prompts/<名>.txt` 复制到 `baselines/prompts/`（不要放在 `prompts/` 旁边，会被当成新任务）。之后只在 `adapt/` 上做局部修改，随时可以和 `baselines/` 对比。
2. **一次只改一处**：每轮只改一个维度（构图 / 文字位置 / 比喻 / 某个元素），其他原样不动；改了什么写成一句话告诉用户。
3. **不要整段重写提示词**，尤其不能重写风格块。
4. **模糊意见先翻译**：「丑」「挤」「不精致」先拆成 2–3 个具体假设让用户选（线条太粗？留白不够？颜色太多？），或每个假设各出一版。
5. **换风格先问**：「是换风格，还是在这个风格里调？」换风格就回到阶段 2–3。
6. **留白靠改结构**：写「留白 6%」实测只有 1.5%；要留白就减元素、拿掉底色块和卡片框。
7. 改动之间不能矛盾（同时要「饱满」又要「留白」）。

## 写回风格库

- 被选中的图：`python3 $S/add_sample.py <风格编号> <图片> [--note "一句说明"]`，自动缩略、放进样张目录、写进卡片（内置风格会顺带重建索引）。
- 档位按选中张数：1 张待验证、2 张特定、3–4 张常用、≥5 张且跨 ≥2 类场景主力；同一风格在某类场景没被选，就写进卡的「不适合」。
- 新踩的坑写进卡的「已知坑」或 `reference/lessons.md`。
