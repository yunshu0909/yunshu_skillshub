# 阶段 1：画面单（风格中立）

**目标**：把要出的每张图定成一张「画面单」。画面单只写内容，不写风格；同一份画面单可以配任何风格。

## 来源

- 用户已经给了图清单 / 每张图的文案：直接转成画面单。
- 只有一篇文章：Claude 先读完，按「一张图只讲一个判断」拆，**写好画面单先给用户确认**，确认后再进阶段 2。

## 每张图写什么（模板 `templates/scene.md`）

| 字段 | 说明 |
|---|---|
| 图号 | 1、2、3… 系列图可用 R-W（头图）/ R-Q（次图） |
| 画幅 / 用途 | 只用实测过的：21:9 公众号头图、16:9 正文 / X、1:1 方图 / 次条、3:4 小红书、9:16 手机全屏、2:1 一切二 |
| 讲什么 | 一句话核心判断 |
| 内容类型 | 对比 / 数据 / 流程 / 清单 / 故事 / 分工 / 漏斗 / 时间线 / 一句话 / 海报 / 表情包（决定推荐哪些风格，见 `reference/recommend.md`） |
| 画面素材 | 可选：可以用的比喻、角色（现编角色要写清外观，后面每张都照抄这段描述） |
| 必含文字 | 每条用「」包住，前面写它的角色，如 `- 标题：「……」`、`- 左侧标签：「……」`。角色名用位置 / 中性词，**别用画面里本来就会写的词**（第一关、Step 1、第 1 名），否则会被一起画上 |

## 规则

- 文字越少越好：标题 + 2–4 条短标签 / 结论。6 条以上要考虑拆图。
- 数字、事实来自原文，不编；虚构内容（活动、店铺）在画面单里注明「虚构」。
- 系列图 / 表情包要同一角色：把角色外观写成一句固定描述，后面每张原样复用。
- 真实存在的角色（用户的宠物、产品 IP）：要求用户给参考图，放任务目录 `ref.png`。
