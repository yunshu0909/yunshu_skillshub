# 阶段 3：风格适配（核心）

**同一张画面单，换风格时画面要重新设计。** 这是本 skill 和「换个风格词」最大的区别。

实测：同一份画面单机械套 12 种风格，用户一张没选；按风格重新设计后（像素：内存条 = 血条、窗口 = 围攻的小怪；漫画：分格代替箭头、结论进对话气泡），整套全选。

## 每张图 × 每种风格，写一个 `adapt/<图号>-<风格编号>.txt`

1. 打开风格卡，读「叙事语法」和「文字放在哪」。
2. 把画面单的核心判断翻译成这个风格的**原生比喻**：
   - 数据对比 → 复古广告是推销员负重不同；3D 动画是台秤上的账单厚薄；积木是一块 vs 一座塔。
   - 流程 → 桌游是棋盘格；列车是车厢；玩具屋是楼层；像素是关卡。
   - 前后对比 → 漫画是两格分镜；纸雕是一框两半一暗一亮；皮影是幕布两场。
3. **放进一个场景 / 舞台**，不要三个图标平铺加标签（用户不选）。
4. 给每条文字找这个风格里的载体（缎带、价签、木牌、对话框、旁白框、铭牌…），在画面描述里写「X 上写 Y 那条文字」，**不要在描述里用「」**，引号只在文字清单里出现。例：写「木牌上写标题」，不写「木牌上写『任务准备』」。
5. 写主体占比：「每个约占画面四分之一宽」「占画面高度约七成」。
6. 第一句写画幅（见 `reference/formats.md`），21:9 写「重要内容放中间六成」，9:16 写「上下各留一成只放背景」。
7. 文字清单原样从画面单复制。

格式见 `templates/adapt-example.txt`。写完跑 `check_prompts.py`。

## 小心

- 多角色时写清区别（颜色、道具、体型），否则会长得一样。
- 角色描述跨图原样复用（系列图 / 表情包）。
- 别为了适配改文字：文字是唯一真值，只能改它放在哪。
