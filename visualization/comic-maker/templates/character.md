# 第 0 步：准备角色

漫画的主角是一个固定的老师角色。**画风跟着角色参考图走**，所以角色图定了，整个系列的画风就定了。

## 角色档字段

| 字段 | 必填 | 怎么写 | 用在哪 | 例子 |
|---|---|---|---|---|
| 角色ID | 是 | 英文小写，不带空格 | 文件夹名、切换角色 | `juzi` |
| `--ref` | 是 | 角色图，png / jpg / webp 都行，会被**复制并转成** `ref.png` 存进角色档，原图不动 | 每页出图的参考图 | `out/A.png` |
| `--name` | 是 | 中文名 | 对话里的称呼、汇报 | 橘子 |
| `--name-en` | 是 | 英文名或拼音 | 提示词里指代角色（`Speech bubble from Juzi`） | Juzi |
| `--species-en` | 是 | 英文物种 / 身份 | 提示词主角那一句 | Orange Cat / Little Girl |
| `--desc-en` | 是 | 英文外貌一句，**照着图写** 3–5 个最有辨识度的特征：体型、毛色 / 发色、配饰、服装、表情 | 提示词主角那一句括号里，每页原样照抄 | chubby round orange tabby cat, round thin-rimmed glasses, red knitted scarf, rosy cheeks, cheerful smiling eyes |
| `--desc-cn` | 是 | 中文外貌短语，**不带名字**，能直接接名字（「<desc_cn><name>」） | 讲解 PPT 小课堂世界的画面描述 | 戴圆框眼镜、系红围巾的胖橘猫 |
| `--series` | 是 | 系列名，4–6 个字 | 封面彩旗（一面一个字）、封面大标题 | 橘子小课堂 |

**写完角色档先给用户看一遍**（名字、外貌、系列名），用户说对再保存。

## A. 已经有自己的 IP

1. 用户给一张清楚的角色图和名字。最好是：单个角色、正面或半身、背景干净（透明背景也行）、图里没有文字。
2. 看图写角色档（上表），给用户确认。
3. 保存并设为默认：

```bash
python3 $S/settings.py add <角色ID> --ref <图片> --name 橘子 --name-en Juzi --species-en "Orange Cat" \
  --desc-en "chubby round orange tabby cat, fluffy fur, round thin-rimmed glasses, red knitted scarf, rosy cheeks, cheerful expression" \
  --desc-cn "戴圆框眼镜、系红围巾的胖橘猫" --series 橘子小课堂
```

第一个角色会自动设为默认；以后多个角色用 `settings.py use <角色ID>` 切换。

## B. 还没有 IP：生成候选

1. 问用户三件事（一次问完）：
   - 画什么：哪种动物 / 什么样的人？
   - 标志性配饰 1–2 个（眼镜、围巾、帽子、背心…）
   - 什么画风？默认**彩铅水彩**（温暖、手绘感）；也可以 Q 版卡通、3D 动画等。
2. **候选单独建一个目录**，和后面的漫画任务目录分开，比如 `<工作目录>/角色候选/prompts/A.txt`、`B.txt`…。写 3–4 个候选（赶时间 2 个也行），候选之间在体型、配饰、表情上有区别，画风相同。
3. 模板如下，**【】里的内容必须按用户的回答换掉**，其余照抄：

```
1:1 方图，角色设定图。一只【胖乎乎、圆滚滚的橘猫】，【戴一副圆框小眼镜，脖子上系一条红色小围巾】。正面半身像，【坐着，两只前爪交叠放在身前】，【笑眯眯地看着镜头，脸颊微微泛红】，身旁一颗小星星在闪光。整体是【彩铅 + 水彩手绘质感，柔和的粉彩】，浅色干净的纸张背景，大量留白，线条柔和，温暖治愈，像儿童绘本里的角色。只画这一个角色，画面里不要任何文字、字母、数字、签名。
```

   - 默认半身像（角色看得最清楚）。要全身就把「正面半身像」改成「正面全身像，从头到脚完整入画」，不写的话脚可能被裁掉。
   - 人物、鸟类等把「前爪」改成手、翅膀。
   - 写完提示词里不要留【】符号。
   - 例子见 `examples/character/juzi-prompt.txt` 和 `juzi.jpg`。
4. 不垫图出图：`python3 $S/render_codex.py <工作目录>/角色候选 --no-ref --title "角色候选"`，打开 `review.html` 给用户挑。
5. 用户挑一个；想微调就**只改一处**（比如换围巾颜色）再出一版。
6. 选中的图按「A」的第 2–3 步写角色档、确认、保存（`--ref` 直接用 `角色候选/out/A.png`）。

## 注意

- 角色图里**不要有文字**，不然每页都可能带上。
- 不是四足动物时：提示词模板里 `waving one paw`、`front paws` 这类写法改掉（人用 hand，鸟用 wing，企鹅用 flipper；模板里统一写成 `<hand>` 占位）。
- 想换画风 = 换一张角色图（同一个角色用新画风再生成一次，存成新的角色ID）。
