# 布局模式库

## 核心原则

1. **每格是场景**，不是信息点
2. **用画面讲故事**，不用文字列表
3. **重要内容给大格**，次要内容给小格
4. **有呼吸感**，不要太紧

---

## 布局模式

### 模式1：单图（1格）

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│           整张都是一个场景           │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

**适用场景**：开场大图、重要时刻、结尾

---

### 模式2：上下两格

```
┌─────────────────────────────────────┐
│                                     │
│           上半部分 (40-50%)          │
│                                     │
├─────────────────────────────────────┤
│                                     │
│           下半部分 (50-60%)          │
│                                     │
└─────────────────────────────────────┘
```

**适用场景**：对比、转折、因果关系

---

### 模式3：上大下小三格

```
┌─────────────────────────────────────┐
│                                     │
│           大格 (40%)                 │
│                                     │
├──────────────────┬──────────────────┤
│                  │                  │
│   小格1 (30%)    │   小格2 (30%)    │
│                  │                  │
└──────────────────┴──────────────────┘
```

**适用场景**：一个主要内容 + 两个补充

---

### 模式4：上小下大三格

```
┌──────────────────┬──────────────────┐
│                  │                  │
│   小格1 (30%)    │   小格2 (30%)    │
│                  │                  │
├──────────────────┴──────────────────┤
│                                     │
│           大格 (40%)                 │
│                                     │
└─────────────────────────────────────┘
```

**适用场景**：两个铺垫 + 一个结论

---

### 模式5：标准四格

```
┌─────────────────────────────────────┐
│           标题区 (10-15%)            │
├─────────────────────────────────────┤
│           格子1 (25-30%)             │
├─────────────────────────────────────┤
│           格子2 (25-30%)             │
├─────────────────────────────────────┤
│           格子3 (25-30%)             │
└─────────────────────────────────────┘
```

**适用场景**：连续的场景、痛点列举

---

### 模式6：混合四格

```
┌─────────────────────────────────────┐
│           大格 (30%)                 │
├──────────────────┬──────────────────┤
│   小格1 (20%)    │   小格2 (20%)    │
├──────────────────┴──────────────────┤
│           大格 (30%)                 │
└─────────────────────────────────────┘
```

**适用场景**：希望→问题(多个)→解决

---

## 每格内容模板

每格需要填写：

```
| 格子 | 大小 | 画面描述 | 旁白/标注 | 对话气泡 |
|------|------|----------|-----------|----------|
| 1 | 大/小 | 谁在做什么 | 旁白文字 | "对话内容" |
```

---

## 比例说明

- **3:4 竖版**：适合公众号、小红书
- **9:16 竖版**：适合手机阅读
- **1:1 正方形**：适合社交媒体

---

## 注意事项

1. **格子不要超过4个**：太多会显得杂乱
2. **大格用于重点**：开场、转折、结尾
3. **小格用于过渡**：铺垫、补充
4. **留白很重要**：不要把格子塞满
