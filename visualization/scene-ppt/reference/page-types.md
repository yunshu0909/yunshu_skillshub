# 页型 → 场景写法

一套 PPT 在这些页型里轮换；**同一种场景结构不要连续用两次**（连续两页「左右对比」就换一页成「特写」或「流程」）。

| 页型 | 场景写法 | 文字 |
|---|---|---|
| 封面 | 世界的全景或招牌时刻（后厨开门营业、药铺挂匾），主角在画面里 | 系列名 / 标题 / 副标题 |
| 目录 | 世界里的「菜单」：菜单板、技能栏、药柜一排抽屉、检查单目录页 | 标题 + 3–6 条 |
| 章节 | 同一个物件反复出现、每章变化（第 N 个抽屉拉开、第 N 张分隔卡亮起） | 编号 + 章节名 |
| 对比 | 同一个角色两种处境，左右两半（被淹没 vs 从容取用）。**物料只有一边**（只说了好的做法）时别硬凑右卡写「—」，改成「特写」：一个大场景 + 一张要点卡 | 标题 + 左卡 + 右卡 |
| 流程 | 世界里的一条路线：小路踏脚石、柜台从左到右、四格连环画、赛道站点 | 标题 + 每步名称 + 一句说明 |
| 分层结构 | 世界里天然分层的东西：三层书架、目录卡 → 书 → 书库、技能书封面 / 目录 / 附录 | 标题 + 每层一句 |
| 误用 / 反例 | 两个很像的东西拿错了（钥匙、抽屉、手提箱、轮胎架） | 标题 + 两个签条 + 1–2 句结论 |
| 版本迭代 | 台阶、长大的植物、越来越多的小人、越来越精致的作品 | 标题 + 每版一句（数字只用原文） |
| 结论 | 主角和成果的一个定格动作 | 一句话结论 + 副句 |
| 结尾 | 和封面呼应（同一场景收工、合上的手册） | 一句话总结 |

## 每页的骨架（用户认可的「像 PPT」）

- 标题有固定载体、固定位置。
- 要点写在清楚可读的卡片 / 签条上，不要缩成场景里的小立牌。
- 图在讲解：角色在做事，不只是物件陈列。
- 文字是版面的主角之一，不是场景里的道具。
