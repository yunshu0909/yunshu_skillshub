# 世界库

每个世界写：ID、映射（谁 / 什么对应什么）、能自然生出的场景、画风（`styles/` 卡号）、标题和文字载体、作者评价、样张（`reference/world-samples/`）。
世界选择页（`scripts/world_picker.py`）读这份文件：**有样张的世界才给用户选**。

**选世界的标准**：① 世界里有「新手照手册干活」的关系（大多数方法论都能映射）；② 能生出 5 种以上不同场景；③ 有原生的文字载体。

档位（作者评价）：**全选** = 作者整组都标了喜欢；**可用** = 作者觉得「还行」。

**样张的内容都是讲 AI / Skill 的。** 换成别的主题时，映射表要按这次的物料重新想（谁是新手、什么是手册），比喻会歪曲原文概念时主动提出来。

## 小课堂（全选）

- ID：classroom
- 映射：你的角色 = 老师；白色小机器人 = AI（**讲非 AI 主题时，小机器人当学生或助教**，写进映射表）；黑板、便签卡、书架、流水线 = 概念道具。
- 场景：黑板讲解、踏脚石小路、书架三层、小工厂流水线、浇水长树、钥匙开门、天平和测试台。
- 画风：N49 角色手绘课件；**必须有角色**（`settings.py get-character`，出图加 `--ref`）。
- 载体：左上大号手写标题 + 浅色水彩色带；要点在圆角便签卡、手绘小木牌。
- 评价：作者的 IP 版 30 页「质量超级好」；换成示例角色橘子实测效果一致。
- 样张：classroom-1.jpg, classroom-2.jpg, classroom-3.jpg

## 后厨（全选）

- ID：kitchen
- 映射：主厨 = 人；学徒 = AI；口头交代 = Prompt；菜谱 + 分格备料架 = Skill；写 Skill = 把老师傅手艺写成菜谱。

- 评价：4 页全选。样例提示词：`examples/kitchen/`。

## 新增世界

用户想要库里没有的世界：在 `~/.scene-ppt/worlds/<世界ID>.md` 照上面的格式写一节（档位写「我的」），画风用 `styles/` 里已有的卡（或在 `~/.scene-ppt/styles/` 新写一张，编号 `U01` 起），出 1–2 页试图；**用户说喜欢**，把图缩略后放 `~/.scene-ppt/worlds/samples/`，在「样张」一行写上文件名，才进选择页。
