# 实测规则与证据（作者 2026-10 实测）

| 规则 | 证据 |
|---|---|
| 「做成 PPT」= 图片，不是 .pptx | 准备装 pptxgenjs 时用户说「我的意思是 PPT 做成图」 |
| Claude 设计每页、定每个字；Codex 只原样出图 | 对照实验：Codex 自己设计的更素，还把原文标题全改写了；用户选 Claude 版 |
| **换世界观，不要换皮** | 同一骨架换 8 种画风，作者「底层是一个模板，缺乏新场景」；换成 6 个新世界「都还行」；后厨、RPG 8 页全选 |
| 机械套用别的风格的画面不行 | 把小课堂版画面直接换风格，作者「你没理解我的意思……跟角色没关系」 |
| 要「像 PPT」：页面感 + 讲解感 | 实物摄影 27 页：「不如小课堂，整体不像 PPT」；Claude + Codex 独立判断都是「像静物广告，不像课件」 |
| 平面信息图、AI 模板感的正式风不要 | 扁平商务插画、浓色编辑风等几种正式风都「感觉一般」（已从风格库去掉） |
| 咨询 / 投行风只有在内容有数据时才可能好 | 「对，就是这种感觉」→ 加密后「凑合，不好不坏」；教程文章只有 60 / 65 两个数字，表格里全是字 |
| 调研出的「观点标题、苹果式极简」不是用户痛点 | 小课堂版标题全是「差别一：调用方式」这种题目，用户照样喜欢 |
| 角色名不要用编号、分层词；画面描述别写「写甲卡」 | 「第一关」「上层/中层/下层」「甲卡/乙卡」都被画上过；改成直接引用那句话后消失 |
| 原文没有的效果别编 | PPT Skill 3.0 / 4.0 原文没打分，Claude 起初写了「质量明显提升」，已删成「—」 |
| 风格块里不能有「」 | 一张风格块写了「关键结论」框，check_prompts 拦下 |
| 标题载体全套统一 | 木牌标题版全选 |
| 等出图别用 `pgrep -f "render_codex.py"` | 会匹配到自己那条等待命令，永远不结束；看 log 里「成功 x/y」 |
| 长套一次出完再挑 | 27 页约 30 分钟（4 批并行）；30 页 N49 约同 |
