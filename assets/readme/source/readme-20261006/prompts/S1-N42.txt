【风格基准（唯一允许）】
等距视角像素艺术：45° 等距的小岛或小房间，清晰的方形像素格，明亮的有限调色板，像独立游戏里的场景。文字为清晰粗黑体（文字本身不像素化），排在画面空白处。
不要：平滑矢量、3D 渲染、写实、模糊。
整张图只用这一种风格，不得混入其他风格。

【画面与版式】
21:9 超宽横版。标题和主体放中间约六成宽，两端只放氛围背景。系列场景图之一：漂浮在云上的等距像素小房间室内特写。像独立游戏的一幕，像素清晰，配色以奶油白、深松绿、蓝灰与暖杏橙为主，奶油白背景上只有很浅的云与小星点。
画面上方居中是一块有小铆钉、挂着藤蔓的漂浮像素木头招牌，约占画面四成宽，写标题，第二行用较小字号写副标题。中文字是工整可读的粗黑体，不像素化。
招牌下方是一间漂浮的等距小房间剖面，占画面约六成宽、六成高，房间外沿有苔藓、小花和一小块石头底座。
房间是一个安静的思考小亭：木地板、软坐垫、一块小黑板、窗外有树。地上有一团缠在一起的毛线，狗子盘腿坐在坐垫上，正和橙色搭子一起把毛线理开；理顺的那一端连到三盏并排亮起的小灯笼，三盏灯笼是整个画面最亮的地方。绿色搭子在旁边举着一盏提灯照亮毛线，像在换个角度看。狗子约占画面高度三分之一，两位搭子各约五分之一。
主角为参考图里的云舒狗子：圆脸、黑灰白毛色、白色口鼻、尖立耳、大眼睛、蓝色鸭舌帽，保留辨识度但转换为精致等距像素角色。参考图仅用于狗子身份，不复制参考图的构图和背景。
橙色搭子是杏橙色圆头小机器人，白色身体，两侧圆形耳罩，头顶一根短天线，脸是深色屏幕上两只椭圆亮眼。绿色搭子是青绿色方头小机器人，方形身体，头顶一根短天线，脸是深色屏幕上两只方形亮眼。
阳光温暖，房间里有暖色灯光，精致饱满而不拥挤，重要人物都在中央六成。屏幕、纸张、书本、黑板上只有抽象线条和色块，不含任何字母、数字或代码。不要画出画面描述以外的人物或动物，不要圆形头像框、标签胶囊、网页按钮、面板 UI、徽章网格、真实软件商标。
