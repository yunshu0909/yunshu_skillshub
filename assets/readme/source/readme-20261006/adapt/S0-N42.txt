21:9 超宽横版。标题和主体放中间约六成宽，两端只放氛围背景。系列场景图之一：漂浮在云上的等距像素小房间室内特写。像独立游戏的一幕，像素清晰，配色以奶油白、深松绿、蓝灰与暖杏橙为主，奶油白背景上只有很浅的云与小星点。
画面上方居中是一块有小铆钉、挂着藤蔓的漂浮像素木头招牌，约占画面四成宽，写标题，第二行用较小字号写副标题。中文字是工整可读的粗黑体，不像素化。
招牌下方是一座漂浮在云上的等距长条小岛，占画面约七成宽、五成高，岛上一条浅色石板小路从左到右串起三个相连的小场景，每个场景约占画面五分之一宽，门前各插一块小木头路牌，依次写步骤一、步骤二、步骤三的文字：
- 左边是一张小工作台，狗子刚做好一件小作品（一座发光的小模型屋），正开心地举起它；
- 中间是一张写字台，台上摊开一本很大的厚皮面手册，狗子坐在台前用羽毛笔把刚才的做法认真写进手册，手册上只有抽象线条，旁边摞着几本同样的手册；
- 右边是另一张工作台，绿色搭子捧着那本手册翻看，橙色搭子照着手册动手搭出一座一模一样的发光小模型屋。
同一只狗子在左边和中间各出现一次，用小路上浅浅的脚印连起来，表示同一个人先做事、再写下来；两位搭子只在右边出现。狗子每次约占画面高度四分之一，两位搭子各约五分之一。

橙色搭子是杏橙色圆头小机器人，白色身体，两侧圆形耳罩，头顶一根短天线，脸是深色屏幕上两只椭圆亮眼。绿色搭子是青绿色方头小机器人，方形身体，头顶一根短天线，脸是深色屏幕上两只方形亮眼。
