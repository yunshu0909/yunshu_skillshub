## 风格块（逐字粘贴，不得改写）

```style
等距视角像素艺术：45° 等距的小岛或小房间，清晰的方形像素格，明亮的有限调色板，像独立游戏里的场景。文字为清晰粗黑体（文字本身不像素化），排在画面空白处。
不要：平滑矢量、3D 渲染、写实、模糊。
```

## 叙事语法（适配画面时照这个设计）

- 世界：一座漂浮在云上的等距小岛 = 一个系统或一个项目。
- 模块：岛上的建筑 = 功能（报社、画室、修理铺…），门口一个小人在干活。
- 流动：水塔、管道把发光像素方块送进屋里。
- 系列图：头图是大岛全景，次图是同一角色站在小岛上的特写。
- 大标题（封面、PPT 标题）：写在一块漂浮的像素木头招牌上（像素描边 + 小铆钉），不要让粗黑体直接浮在天空——用户说「字体有点奇怪」，换招牌后选中（2026-10-03）。

## 文字放在哪

白色小浮标标签；标题在空白天空里，字不像素化。
